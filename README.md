# Compugued — Bio Link responsivo

## Archivos
- `index.html`: estructura, textos, enlaces y contenido.
- `styles.css`: diseño visual y adaptación a celulares, tablets, laptops y pantallas grandes.
- `script.js`: enlaces editables para categorías y redes sociales.

## Cómo abrirlo
1. Descomprime la carpeta.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. Para publicarlo, sube los tres archivos a tu hosting manteniendo los nombres y la misma carpeta.

## Qué debes personalizar antes de publicarlo
1. En `index.html`, cambia el nombre, eslogan, descripción, ubicación y textos.
2. Sustituye `51999999999` por tu número de WhatsApp con código de país, sin `+`, espacios ni guiones. Para Perú, el prefijo es `51`.
3. En `script.js`, edita `CATEGORY_LINKS` y `SOCIAL_LINKS` con tus enlaces reales.
4. Cambia las URL de las imágenes en `index.html` por tus fotos de productos. Las imágenes actuales son ilustrativas y requieren conexión a internet.
5. Si cambias nombres de categorías, conserva los atributos `data-link` o actualiza las claves en `script.js`.

## Notas
- No requiere instalar dependencias ni usar JavaScript para el diseño responsive; JavaScript solo asigna los enlaces.
- La fuente Inter y las imágenes se cargan desde internet. Puedes descargarlas y alojarlas localmente si deseas que el sitio dependa menos de servicios externos.
- Los enlaces y datos de ejemplo deben ser reemplazados por los de tu negocio antes de compartir el bio link.
